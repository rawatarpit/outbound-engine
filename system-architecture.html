Each brand has intents — e.g. "brands launching products needing video ads". Intents define the search strategy. Pipeline runs on a timer, cycling through brands and their intents.
Query generation agent creates search queries per intent + signal type. Each signal maps to a set of adapters (e.g. growth_activity → yc, producthunt, news, search, wellfound, linkedin, meta_ads). The agent chooses which to use.
Phase 1 runs all selected adapters in parallel. Each returns candidate companies (domain + URL + signal).

FIXED Previously, mergeCompanyData's uniqueDomains stripped www., causing upsert conflict key mismatch. Candidates silently dropped. Now always-keeps.
Per candidate, runs FORGE (NVIDIA LLM) + scrape_extract.py in parallel. FORGE analyzes domain. scrape_extract crawls website via Crawl4AI, extracts company data via NVIDIA LLM, grounds against scraped text.

FIXED OpenAI max_retries=2 (default) × 3 Python retries = 90s/attempt → death spiral. Now max_retries=0, 45s timeout, 180s exec.
NEW After main site extraction, LLM finds Instagram/LinkedIn/FB/Twitter URLs in page content. Each social page scraped with Crawl4AI, then LLM extracts email, phone, bio, location. Emails merged into company record.
Upsert into discovered_companies via source_url conflict key. raw JSONB stores everything: social_links, social_contacts, extraction_confidence, key_people, emails.
Two brands consume discovered companies:
  • Relayforge — AI sales platform
  • Fruitloop — Research tool
Stages: researching → qualified → draft_ready → replied → negotiating. Agent chains run sequentially per company.

🔍 Root cause: Why Meta Ads + Maps results were lost

🐞 Bug 1: Domain prefix stripping

workerTools.ts's uniqueDomains used new URL(url).hostname, stripping www..

Domain normalized to example.com but source_url stayed https://www.example.com.

Supabase upsert checks source_url conflict → no match → silently skipped

+
🐞 Bug 2: LLM timeout death spiral

OpenAI max_retries=2 (default) × 3 Python retries = ~90s per attempt.

3 attempts + backoff sleeps (5+10+20s) = ~290s total.
Node.js execFile timeout at 120s → subprocess killed → null returned → company dropped.

✅ Both fixed. Meta Ads / Maps fire on-demand per signal — next matching cycle, all candidates survive.
